## 🎨 التخصيص السريع

### تغيير السعر:
```javascript
const PRODUCT_PRICE = 1500; // من 1200 إلى 1500
```
**الملف:** `index.html` - البحث عن السطر ~315

### تغيير الألوان:
```css
:root {
    --color-primary: #2d5016;    /* الأخضر الداكن */
    --color-accent: #8b4513;     /* البني الترابي */
    --color-light: #f5f1ed;      /* البيج الفاتح */
}
```
**الملف:** `index.html` - السطور 11-20

### تغيير الشعار:
```html
<div class="logo-icon">🌿</div>
<span>Root Forest</span>
```
**الملف:** `index.html` - البحث عن `<div class="logo">`

## 🐛 حل المشاكل الشائعة

### المشكلة: "الخط غير صحيح"
**الحل:** تأكد من الاتصال بالإنترنت (Google Fonts)

### المشكلة: "الألوان غير صحيحة"
**الحل:** امسح Cache المتصفح (Ctrl+Shift+Delete)

### المشكلة: "لا تعمل البلديات"
**الحل:** تحقق من أن الولاية محددة أولاً

### المشكلة: "المودال لا يظهر"
**الحل:** تحقق من أن السلة فيها منتجات
