# 🎬 دليل الفيديو التعليمي - Root Forest Premium

## 📺 فصول التعليم

---

## الفصل 1: البدء الأول

### ⏱️ المدة: 2 دقيقة

#### الخطوات:
1. **افتح الملف:**
   - انقر بزر الماوس الأيمن على `index.html`
   - اختر "فتح مع" → متصفح الويب

2. **استكشف الصفحة:**
   - لاحظ شريط الملاحة العلوي
   - اقرأ الرسالة الترحيبية
   - شاهد صورة المنتج (SVG)

3. **جرّب الأزرار:**
   - اضغط "إضافة إلى السلة" ← سيظهر تنبيه
   - شاهد عداد السلة يتحدث
   - لاحظ تحديث الإجمالي

---

## الفصل 2: إضافة المنتجات

### ⏱️ المدة: 3 دقائق

#### التعليمات:

**الخطوة 1: إضافة المنتج للسلة**
```
🖱️ اضغط على "🛒 إضافة إلى السلة"
→ ستسمع تنبيه "تمت الإضافة"
→ عداد السلة يصبح "1"
```

**الخطوة 2: إضافة منتج آخر**
```
🖱️ اضغط مرة أخرى على "إضافة إلى السلة"
→ عداد السلة يصبح "2"
→ الإجمالي يتحدث: 2400 دج (1200 × 2)
```

**الخطوة 3: عرض السلة**
```
🖱️ انتقل إلى قسم "سلتك"
→ شاهد المنتج مع الكمية
→ لاحظ أزرار +/-
→ رأيت السعر الكلي
```

---

## الفصل 3: تعديل الكمية

### ⏱️ المدة: 2 دقيقة

#### التعليمات:

```
📊 عرض السلة الحالية:
┌──────────────────────────────┐
│ Root Forest مسحوق بروتين     │
│ [−] 2 [+]  2400 دج  [حذف]   │
└──────────────────────────────┘

✏️ تعديل الكمية:
1. اضغط على [+] → الكمية تصبح 3
2. الإجمالي يصبح 3600 دج (1200 × 3)
3. اضغط على [−] → الكمية تصبح 2
4. لاحظ التحديث الفوري
```

## الفصل 6: ملء نموذج الشراء

### ⏱️ المدة: 5 دقائق

#### حقول النموذج:

**1. الاسم الكامل:**
```
📝 ادخل اسمك:
[أحمد محمد علي]

✅ يجب أن يكون:
- ليس فارغ
- من 3-100 حرف
```

**2. رقم الهاتف:**
```
📱 ادخل الهاتف:
[0671234567]

✅ يجب أن يكون:
- رقم جزائري صحيح
- يبدأ بـ 0 أو +213
- 10 أرقام
```

**3. العنوان:**
```
🏠 ادخل عنوانك:
[الجزائر، حي القبة، شارع...]

✅ يجب أن يكون:
- واضح وكامل
- يتضمن الشارع والحي
```

**4. الولاية:**
```
🗺️ اختر الولاية:
[▼ الجزائر]

✅ اختيارات متاحة:
- الجزائر
- البليدة
- تيبازة
- ... و+15 ولايات
```

**5. البلدية:**
```
🏘️ اختر البلدية:
[▼ الجزائر]

✅ تتحدث حسب الولاية:
- إذا اخترت الجزائر:
  └─ الجزائر، بن عكنون، القبة...
  
- إذا اخترت البليدة:
  └─ البليدة، الأفرون، بوعريريج...
```

## الفصل 10: استخدام المتصفح

### ⏱️ المدة: 2 دقيقة

#### الأدوات المفيدة:

**1. Console (لوحة التحكم):**
```
🖱️ اضغط F12 → Console Tab

📝 اختبر أوامر مثل:
- cart  ← شاهد السلة
- PRODUCT_PRICE  ← سعر المنتج
- addToCart()  ← أضف للسلة
```

**2. Developer Tools:**
```
🖱️ اضغط F12 → Elements Tab

🔍 فحص العناصر:
- الوانات CSS
- الأحجام والمسافات
- الخطوط المستخدمة
```

**3. Network Tab:**
```
🖱️ اضغط F12 → Network Tab

📊 راقب الطلبات:
- تحميل الخطوط
- طلب الـ API
- رسائل الخطأ
```

## الفصل 11: المشاكل الشائعة

### ⏱️ المدة: 3 دقائق

#### المشكلة 1: الخط غير صحيح
```
❌ الأعراض:
- الخط يبدو غريب
- النصوص العربية مشوهة

✅ الحل:
1. امسح Cache (Ctrl+Shift+Delete)
2. حمّل الصفحة (F5)
3. تأكد من الإنترنت
```

#### المشكلة 2: الألوان غير صحيحة
```
❌ الأعراض:
- الألوان مختلفة عن الصور

✅ الحل:
1. امسح Browser Cache
2. جرب متصفح آخر
3. تحقق من إعدادات العرض
```

#### المشكلة 3: الأيقونات ظاهرة بشكل غريب
```
❌ الأعراض:
- 🌿 بدل الورقة تظهر مربعات

✅ الحل:
1. حدّث المتصفح
2. استخدم Chrome أو Firefox
```

#### المشكلة 4: النموذج لا يرسل
```
❌ الأعراض:
- زر التأكيد لا يعمل

✅ الحل:
1. تحقق من الأخطاء (Console)
2. تأكد من اتصال الإنترنت
3. جرب متصفح آخر
```

## الفصل 12: تخصيص الموقع

### ⏱️ المدة: 5 دقائق

#### تغيير السعر:

**البحث:**
```
1. افتح index.html بمحرر نصوص
2. ابحث عن: const PRODUCT_PRICE
3. غيّر الرقم من 1200 إلى (سعرك)
4. احفظ (Ctrl+S)
5. حمّل الصفحة (F5)
```

**المثال:**
```javascript
// قبل:
const PRODUCT_PRICE = 1200;

// بعد:
const PRODUCT_PRICE = 1500;
```

#### تغيير الاسم:

```javascript
// قبل:
const PRODUCT_NAME = "Root Forest مسحوق بروتين";

// بعد:
const PRODUCT_NAME = "منتج جديد";
```

#### تغيير الألوان:

```css
/* البحث عن :root */
:root {
    --color-primary: #2d5016;  /* الأخضر الداكن */
    --color-accent: #8b4513;   /* البني الترابي */
    /* غيّر الألوان هنا */
}
```
